# ctx/ — manually adopted files

> The slot for files a human places here by hand because they belong with
> this run — loose notes, feedback, designs that sit beside the kit
> artifacts without being any of them. No tooling writes into this slot,
> nothing else instantiates into it, and import/cleanup diff gates must
> ignore it: ctx/ is never part of an import contract.

Adopt freely. The one rule is provenance: name the file's origin in the
commit that adopts it (`doc(ctx) adopt <file> from <where>`), because a
loose file with no origin is a mystery by the next session.
